calculBA doit être ouvert par son serveur

Cette page a été ouverte directement depuis le dossier (adresse commençant par file://). calculBA a besoin de son serveur Python pour fonctionner.

  1. Fermez cet onglet.
  2. Dans le dossier calculba, double-cliquez sur Lancer_calculBA.bat (ou lancez uvicorn backend.main:app comme indiqué dans le README).
  3. Laissez la fenêtre noire ouverte : le navigateur s'ouvre sur http://127.0.0.1:8000.

N'ouvrez pas frontend/index.html par double-clic.
